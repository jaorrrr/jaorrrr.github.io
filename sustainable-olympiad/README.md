# Sustainable Olympiad: event website

A fast, accessible, multi-page website for the **Sustainable Olympiad**, an international
competition where student teams design real solutions for sustainability challenges.

Live at: `https://jaorrrr.github.io/sustainable-olympiad/`

| Schedule: timeline with live status, Finals programme, `.ics` calendar | `schedule.html` |

## Accessibility (WCAG 2.1 AA)

- Semantic landmarks, skip link, one `h1` per page, logical heading order, `aria-current` navigation.
- Keyboard support everywhere, with a thick two-tone focus ring that is visible on every background.
- An accessibility toolbar (top of every page) with text size (90–200%), dark mode, high contrast,
  text spacing (WCAG 1.4.12) and link highlighting. Preferences are saved in `localStorage` and
  applied before first paint.
- Respects `prefers-color-scheme` and `prefers-reduced-motion`.
- The countdown can be paused (WCAG 2.2.2) and starts paused for reduced-motion users.
- Forms have visible labels, hints, inline errors linked with `aria-describedby`, and a
  GOV.UK-style error summary that receives focus.
- The menu collapses to a hamburger whenever it doesn't fit, including at large text sizes.
- Tested with axe-core: no violations on any page in the light, dark and high-contrast themes.
  No horizontal scrolling at 320px, or with 200% text at 640px and 1280px.

## Editing content

Pages are generated by a small Python script, so the header, footer and shared content only need to be edited once.

```bash
pip install reportlab          # only needed for the PDFs
cd sustainable-olympiad/_build
python3 build.py               # regenerates pages, PDFs, images, calendar and search index
```

- `_build/papers.py` holds the past papers: questions, options, answers, worked solutions and mark schemes.
  After editing a calculation, run `python3 verify_papers.py`, which recomputes every numerical answer.
  The paper PDFs need the DejaVu Sans font (`apt install fonts-dejavu-core`, preinstalled on most Linux systems).
- `_build/content.py` holds all event data: dates, categories, rules, FAQ, news, sponsors and schools.
- `_build/build.py` holds the page templates and `SITE` settings (email, form endpoint, social links).
- `assets/css/main.css` and `assets/js/*.js` are edited directly.

The `_build` folder starts with an underscore, so GitHub Pages does not publish it.

## Before going live

1. **Forms:** set `SITE["form_endpoint"]` in `build.py` to a form backend such as Formspree, Getform
   or Basin, then rebuild. Until then, forms validate fully and then open the visitor's
   email app with the completed message addressed to `contact_email`.
2. **Contact email, address and social links:** these are placeholders in `SITE`. Replace them.
3. **Content:** history, statistics, sponsors, schools and news are illustrative. Replace them with real data in `content.py`.
4. **Photos:** the gallery uses lightweight SVG illustrations in `assets/img/gallery/`.
   Replace them with real photos and update the alt text in `content.py` (`GALLERY`).
5. **PDFs:** generated PDFs are not tagged for screen readers. The same content is
   available as HTML on the Rules page, and the accessibility statement says so.

## Past papers

Four olympiad-level Round 1 papers (2026 and 2025 editions, Senior and Junior divisions): 10 multiple-choice
questions plus multi-step problems on energy, climate, chemistry, ecology and water. Each paper has:

- a printable question paper PDF with a cover page, data sheet and answer lines;
- a mark-scheme PDF with an answer key, worked solutions and how marks are awarded;
- an accessible online practice page with per-question checking, a Part A score and expandable solutions.

All PDFs are also bundled in `assets/docs/past-papers/sustainable-olympiad-past-papers.zip`.

## Third-party services

Nothing third-party loads by default. The schools map loads Leaflet from cdnjs and tiles from
OpenStreetMap only when a visitor selects **Show map**. Share links open the respective social network.
